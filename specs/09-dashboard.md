# 지시서 09 · 조종판 — 자동주행 ON · 긴급 정지 · 실시간 로그

> 번호표(01~08)에 없는 보조 프로그램이라 09를 쓴다. 주행 규칙은 하나도 정하지 않는다. 02~07 주행 프로그램은 바꾸지 않고 그대로 띄운다.

## 목표
노트북·휴대폰 브라우저에서 버튼 하나로 자동주행을 시작하고, 달리는 동안 주행 프로그램이 지금 무슨 판단을 하는지(상태 · 라인센서 · 바퀴 · YOLO로 본 것 · 거리)를 실시간으로 보고, 언제든 긴급 정지한다.

## 규칙표
| 상황 (언제) | 행동 (무엇을) |
|---|---|
| 조종판 실행 | 라즈봇에서 `python3 missions/09_dashboard.py`. 같은 와이파이의 브라우저에서 `http://raspbot-03.local:8080` (안 열리면 `http://라즈봇IP:8080`). 종료는 터미널 Ctrl+C. |
| 「자동주행 ON」 누름 | 안전 확인 체크(바닥에 놓고 사방 1m 비움)가 없으면 시작하지 않는다. 선택한 주행 프로그램(기본 `missions/06_drive_signs.py --trial 회차이름`)을 가상 터미널(pty)에서 별도 프로세스로 띄운다. 한 번에 하나만 띄운다. 미리보기가 켜져 있으면 먼저 끄고 띄운다. |
| 주행 중 로그 | 주행 프로그램의 화면 출력을 줄 단위로 그대로 브라우저에 보낸다(SSE). 같은 내용을 `results/dashboard_날짜시각.log`에 저장한다. `I2C error`·오류 줄은 빨간색, 상태 줄은 초록색으로 표시하고 I2C 오류 횟수를 센다. |
| 주행 중 상태표 | 주행 프로그램이 `results/`에 새로 만든 원시 기록 CSV(06 `drive_signs_*.csv`, 07 `camera_lane_*.csv`, 04 `obstacle_*.csv`)를 따라 읽어 상태 · x1~x4 · 바퀴 네 값 · 인식 이름/점수/상자 높이 · 거리를 표로 보여 준다. 상태 이름 옆에 그 상태의 규칙(지시서 02·04·06·07의 규칙표 요약)을 함께 보여 주고 규칙표에서 현재 상태를 강조한다. CSV가 없는 02는 화면 출력 줄에서 상태를 읽는다. |
| 「긴급 정지」 누름 (또는 Esc 키) | 확인창 없이 즉시. 주행 프로세스에 SIGINT(Ctrl+C와 같은 신호 → 기존에 바닥 시험으로 검증된 종료 경로: 네 바퀴 0 묶음 3회)를 보낸다. 2초 안에 끝나지 않으면 강제 종료(SIGKILL)한다. 프로세스가 사라진 뒤 조종판이 직접 네 바퀴 0 · 부저 끄기 · 초음파 끄기를 0.2초 간격 3회(바퀴 사이 0.01초) 보낸다. |
| 「정상 종료 (아무 키)」 누름 | 가상 터미널에 키 하나(스페이스)를 넣어 주행 프로그램의 「아무 키나 누르면 정지」로 끝낸다. 종료 뒤 처리는 아래와 같다. |
| 주행 프로그램이 어떻게든 끝남 | 종료 코드·사유를 표시한다. 조종판이 직접 네 바퀴 0 묶음 3회를 한 번 더 보낸다(종료 뒤 바퀴가 계속 돈 기록이 log.md에 있음). `results/runs.csv`가 갱신됐으면 마지막 줄을 보여 준다. 이번 주행에서 생긴 CSV · 로그 · 영상(`results/videos/`) 파일 목록과 링크를 보여 준다. |
| 「바퀴 0 다시 보내기」 누름 | 주행 중이 아닐 때만. 위와 같은 정지 묶음 3회. 주행 중에는 거부한다(두 프로세스가 I2C를 동시에 쓰지 않게). |
| 최대 주행 시간(선택) | 값을 적으면 그 시간을 넘길 때 긴급 정지 절차를 자동으로 한다. 기본은 없음. |
| 카메라 미리보기 | 주행 중이 아닐 때만 켤 수 있다(출발 위치 맞추기용). 주행 중 카메라 화면은 보여 주지 않는다 — 주행 프로그램이 카메라를 쓴다. 주행 뒤 블랙박스 영상을 조종판 링크로 연다. |
| 다른 주행 프로그램이 이미 돌고 있음 | `missions/` 프로그램이 다른 터미널에서 실행 중이면 조종판에 경고를 표시한다(시작은 막지 않는다 — 사용자가 판단). |
| 조종판 종료(Ctrl+C) · 오류 | 주행 중이면 긴급 정지 절차를 끝낸 뒤 종료한다. 미리보기도 끈다. |
| 라즈봇이 아닌 컴퓨터에서 실행 | 드라이버(Raspbot_Lib)가 없으면 「직접 정지 명령을 보내지 않았다」고 로그에 남기고 나머지는 그대로 동작한다(노트북 시험용). |

## 성공 기준 (숫자로)
- 장치 없는 검증(`tools/test_dashboard.py`): 가짜 주행 프로그램으로 시작 → 로그 수신 → CSV 상태표 → 키 종료, 긴급 정지(SIGINT) 경로, SIGINT를 무시하는 프로그램의 강제 종료 경로, 종료 뒤 네 바퀴 0 묶음 3회(부저·초음파 끄기 포함), 안전 확인 없는 시작 거부, 동시 실행 거부, 최대 시간 초과 자동 정지, 드라이버 없을 때 안전한 건너뜀, 파일 경로 탈출 차단을 모두 통과한다.
- 실물(라즈봇에서, 사용자 눈으로): 브라우저 「자동주행 ON」 → 06 시작(삐 소리·WAITVISION→FORWARD 표시) / 「긴급 정지」 → 1초 안에 네 바퀴 정지 / 로그 줄이 1초 안에 화면에 보임. 5번 중 5번.
- 긴급 정지 뒤 네 바퀴 전체 정지는 출력만 보고 판정하지 않고 사용자가 확인한다.

## 안전
- 조종판은 바퀴 속도를 정하지 않는다. 조종판이 직접 보내는 바퀴 명령은 0(정지)뿐이다. 속도 한계 150 등은 주행 프로그램 규칙 그대로다.
- 긴급 정지는 확인창 없이 즉시, Esc 키로도 된다. 「자동주행 ON」은 안전 확인 체크가 있어야 한다(AGENTS.md 「바퀴가 도는 프로그램 실행 전 확인」을 체크박스로 대신).
- 주행 프로그램 종료 뒤 조종판이 바퀴 0을 한 번 더 보낸다. 조종판이 끝날 때(오류가 나도) 주행 중이면 긴급 정지 절차를 한다.
- 같은 와이파이의 누구나 접속할 수 있다. 수업용 핫스팟에서만 쓰고, 필요하면 `--host 127.0.0.1`로 띄운 뒤 SSH 터널(`ssh -L 8080:localhost:8080 pi@raspbot-03.local`)로 본다.
- 새로 설치할 것은 없다(파이썬 표준 라이브러리만. 미리보기만 이미 있는 OpenCV 사용).

## 바꿔 볼 값
- 포트 8080(`--port`), 접속 주소 0.0.0.0(`--host`).
- 긴급 정지 뒤 강제 종료까지 기다리는 시간 2초.
- 정지 묶음 3회 · 0.2초 간격 · 바퀴 사이 0.01초(02·04와 같음).
- 로그 보관 2000줄, CSV 표 200줄, CSV 읽기 주기 0.25초.
- 기본 프로그램 `missions/06_drive_signs.py`. 통합 프로그램이 바뀌면 조종판 위쪽 `DEFAULT_PROGRAM`·`PROGRAM_ARGS`만 고친다.
