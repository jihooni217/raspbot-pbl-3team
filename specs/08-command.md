# 지시서 08 · 글로 명령하기 (AI)

## 목표
노트북에서 한국어 문장을 입력하면, AI가 **조가 시험해 본 동작 목록에서 하나만** 골라 라즈봇이 그 동작을 한다. 목록에 없는 일은 안전하게 거절한다.

## 왜
- 발표 날 데모 둘째 판: 다른 조가 우리 예문 하나를 골라 입력하면 라즈봇이 수행해야 한다.
- AI는 바퀴를 직접 몰지 않는다. 숫자(속도·시간)는 조가 정한 값만 쓴다.

## 만드는 것
- `missions/08_command.py`: 문장 입력 → AI 고르기 → 검사 → 동작 → 기록
- AI: 로봇에 깔린 Codex CLI를 `codex exec`(읽기 전용, 추론 low)로 불러 **JSON 한 줄**만 받는다. 20초 안에 답이 없거나 형식이 틀리면 아래 「키워드 고르기」로 대신한다(화면에 "AI 대신 키워드로 골랐어요" 표시).
- `--dry-run`: 바퀴·부저·불빛을 쓰지 않고 고른 동작만 보여 준다 (집에서 시험용)

## 동작 목록 (이것만 허용)
| 이름 | 하는 일 | 숫자 (조가 정함) |
|---|---|---|
| forward | 앞으로 | 속도 40, 1초 (0.5~2초만) |
| backward | 뒤로 | 속도 30, 0.5초 고정 (2026-11-05 사용자 답변) |
| turn_left / turn_right | 제자리 돌기 | 속도 40, 0.6초 (0.3~1.5초만) |
| slide_left / slide_right | 옆으로 (메카넘) | 속도 30, 0.5초 고정 (2026-11-05 사용자 답변) |
| stop | 바로 정지 | — |
| beep | 부저 | 0.3초, 최대 3번 |
| light | 불빛 켜기 | 빨강·초록·파랑·끄기 중 하나 |
| distance | 초음파 거리 말하기 | 바퀴 안 씀 |
| look | 카메라 사진 1장 + YOLO로 본 것 말하기 | 바퀴 안 씀, 사진은 results/command/ |
| refuse | 거절하고 이유 한 줄 | — |

- AI 답 형식: `{"action":"이름","seconds":숫자(선택),"color":"red|green|blue|off"(선택),"count":1~3(부저만·선택),"say":"한 줄"}`
- 목록 밖 이름, 범위 밖 숫자, 두 개 이상 동작, 속도 지정 요청 → **refuse**
- 「계속」「끝까지」「빨리」「벽에 박아」처럼 위험하거나 끝이 없는 요청 → refuse

## 규칙표
| 상황 | 행동 |
|---|---|
| 움직이는 동작을 고름 | 앞(또는 뒤) 초음파가 25cm 안이면 움직이지 않고 거절 |
| 움직이는 중 | 0.05초마다 초음파 확인, 20cm 안이면 즉시 정지 |
| 첫 움직이는 동작 | 「상자 위에 올렸거나 바닥이 비었나요? (y/n)」 한 번 묻고 y일 때만 |
| 후진·옆 이동을 고름 | 뒤/옆 센서가 없으므로 매번 「뒤(또는 옆)가 비었나요? (y/n)」를 묻고 y일 때만 속도30·0.5초. 움직이는 동안 앞 초음파를 계속 확인해20cm 안이면 정지 (2026-11-05 사용자 결정) |
| Ctrl+C 또는 q | 즉시 정지하고 끝냄 |
| 동작이 끝남 | 정지 명령 3번, 결과를 `results/command_log.csv`에 한 줄 (시각·문장·AI답·고른 동작·키워드 대신 여부·결과) |

## 예문 10개 (발표 때 다른 조가 고름)
1. 앞으로 조금 가 줘 → forward
2. 뒤로 살짝 물러나 → backward
3. 왼쪽으로 돌아 → turn_left
4. 오른쪽으로 돌아 봐 → turn_right
5. 오른쪽 옆으로 비켜 줘 → slide_right
6. 멈춰! → stop
7. 경적 울려 줘 → beep
8. 빨간 불 켜 줘 → light(red)
9. 앞에 뭐가 있는지 봐 줘 → look
10. 앞에 벽까지 몇 cm야? → distance

거절 예문 3개: 「속도 200으로 끝까지 달려」, 「벽에 박아 버려」, 「창문 열어 줘」 → 모두 refuse

## 성공 기준 (숫자로)
- 집 시험(`--dry-run`): 예문 10개 중 **9개 이상** 맞게 고름, 거절 예문 **3/3** 거절
- 문장 비슷하게 바꾸기(예: 「앞으로 가」「전진」) 5개 중 4개 이상
- 상자 위 실물: 예문 10개 중 **3개 이상** 성공(과제 기준), 거절 3/3
- 한 문장 처리 시간 20초 안

## 안전
- 전진/제자리 회전은 속도40, 후진/옆 이동은 속도30 고정 (50 넘지 않기), 한 번 최대2초. 후진/옆 이동은0.5초 고정
- 바퀴 돌리기 전에 사용자에게 묻기, 집 시험은 `--dry-run`만
- AI 답은 무조건 목록·범위 검사를 거친다. AI가 코드를 쓰거나 명령을 실행하지 못하게 읽기 전용으로 부른다

## 바꿔 볼 값
- AI 대신 키워드만 쓰면 몇 개 맞나 (AI 있음/없음 비교 → 발표 7장)

## 구현 조건과 집 시험 문장 (2026-11-05)
- Codex 실행 파일은 `~/.vscode-server/extensions/openai.chatgpt-*/bin/linux-aarch64/codex`에서 버전 숫자가 가장 큰 실행 파일을 찾는다. 사용자가 확인한 `exec --skip-git-repo-check -s read-only -c model_reasoning_effort="low" -c service_tier="default"`를 쓴다. 추가로 shell_tool·앱·플러그인·이미지 보기·웹 도구를 끄고 한 문장을 별도 인자로 전달한다. 쉘 문자열로 실행하지 않는다.
- 한 문장20초 상한 안에서 정리 시간을 남기도록 AI 응답 대기는19초까지다. 실패·형식 오류·범위 오류·알려진 요청과 다른 응답은 키워드로 대신 고르고, 키워드 결과도 같은 검사기를 통과한다.
- JSON 한 줄/허용 키만 받는다. 배열·여러 동작·중복 키·코드·speed 항목·문자열/참거짓 숫자·NaN/무한대·범위 밖 값을 거절한다. 원문의 위험 표현·다중 동작·시간·횟수·색도 다시 확인한다. 원문에 없는 시간/횟수를 AI가 바꾸면 대체하고 기본값을 쓴다.
- 전진 기본1초, 회전 기본0.6초, 부저 기본1번이다. 후진/옆 이동은0.5초 고정이다. 부저 반복 사이에는0.3초를 끄며3번의 전체 울림/쉼 시간은1.5초다.
- 실물 정지 문장은 AI를 기다리지 않고 정지한다. q/Ctrl+C는 현재 동작/AI 대기를 중단한다. 마지막 정지는 모든 바퀴0을3회 보내고, 통신 오류가 나도 다른 바퀴 정지를 계속 시도한다.
- `--dry-run`은 바퀴·부저·불빛뿐 아니라 카메라·초음파도 쓰지 않는다. `--keywords-only`는 AI를 호출하지 않는다. `--json`은 자동 비교용 결과 한 줄 출력이다. 결과는 `results/command_log.csv`, 비교 원문/판정/시간은 `results/command/`에 저장한다.
- 바꿔 말하기5개는 비교 전에 고정했다: 「전진」→forward, 「후진해 줘」→backward, 「왼편으로 제자리 회전해」→turn_left, 「우측으로 옆걸음해 줘」→slide_right, 「눈앞 상황을 사진으로 알려 줘」→look. 전체18문장은 `results/command/cases.json`에 있다.
