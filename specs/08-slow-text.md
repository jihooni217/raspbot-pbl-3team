# 지시서 08 · 바닥 「천천히」 글씨 보면 감속 (담당: 수현)

> 2026-11-04 영빈이 쓴 초안을 수현님께 넘기는 것. 숫자는 **제안값** — 담당자가 확정한 뒤 Codex가 만든다.
> 강사님 지시(2026-11-04): 새 물체(「천천히」 글씨)를 알아보는 모델은 **코랩에서 학습**한다. 로터리 감속은 `specs/10-rotary.md`(하은)에서 같은 틀로 다룬다.

## 목표
달리는 중에 바닥의 「천천히」 글씨를 보면 바퀴 속도를 줄이고, 글씨를 지나 일정 시간이 지나면 원래 속도로 돌아온다. 사람·STOP·장애물 정지는 그대로 우선한다. 감속 중에는 불빛(노랑)으로 표시해 영상에서 보이게 한다.

## 담당자가 정할 것 (제안값)
1. 감속 배율 0.7 — 직진 50 → 35, 꺾기 바깥 60 → 42, 탐색 40 → 28. 0.6(30)은 낮은 속도에서 바퀴가 안 돌 수 있어 상자 시험으로 먼저 확인.
2. 유지 시간 — 마지막으로 글씨를 본 뒤 4초.
3. 가까움 기준 — 글씨 상자 **아랫변 y ≥ 240**(화면 480 중 아래쪽일수록 가까움). 멀리서 읽혀 너무 일찍 감속하지 않게. 트랙에서 실측 후 확정.
4. 모델 — 새 클래스 `slow`를 로터리의 `rotary`와 **한 모델**(`models/slow_zones_320.onnx`)로 학습할지, 따로 할지. 하은님과 같이 정한다(사진·라벨링을 한 번에 하는 쪽이 편함).
5. 「구불구불한 길」(S자 구간)은 감속이 아니라 주행(02/07)의 문제다. 02는 가장자리에 닿으면 꺾는 방식이라 느리게 가면 S자를 통과할 가능성이 있다 — 감속 배율을 S자 구간에도 적용할지 담당자가 정한다.

## 규칙표
| 상황 (언제) | 행동 (무엇을) |
|---|---|
| 카메라 · 인식 | 기존 03/06의 「한 스레드 카메라 + 별도 YOLO 스레드」 그대로. 새 모델로 최신 화면을 인식한다. 기존 사람·STOP 인식(640 COCO)은 바꾸지 않는다. |
| 글씨 인정 | `slow` 점수 0.5 이상이고 아랫변 y가 기준 이상인 상자가 **서로 다른 새 결과에서 연속 2회** 보이면 감속 시작. 같은 결과 반복은 세지 않는다(06과 같음). |
| 유지 · 종료 | 마지막으로 본 때부터 4초 유지. 그 안에 다시 보이면 4초를 다시 센다. 지나면 원래 속도. |
| 감속 방법 | 주행 판단(02 `LineFollower` 또는 07 `LaneController`)이 낸 네 바퀴 값에 배율을 곱해 정수로 반올림. 0은 0. 배율은 1을 넘지 않는다. |
| 사람 · STOP · 장애물 · 줄 놓침 정지 | 기존 규칙이 우선. 정지 중에도 감속 시계는 흐르고, 재출발 때 구간이 남아 있으면 감속 속도로 출발. |
| 인식 결과 끊김(1초 초과) | 06 규칙대로 정지. 끊긴 동안을 「안 보임」으로 세지 않는다. |
| 불빛 | 감속 중 노랑 `Ctrl_WQ2812_ALL(1, 3)`, 끝나면 끔 `(0, 0)`. 상태가 바뀔 때만 보낸다. |
| 기록 | 블랙박스 글자 `SLOW 0.7 TEXT`. 원시 CSV 열 추가: 감속배율 · 감속이유 · slow점수 · slow아랫변y. runs.csv 한 줄. |
| 종료 · 오류 | 기존대로 네 바퀴 0 묶음 3회, 불빛 끔, 카메라·YOLO·녹화 정리. |
| 프로그램 | `missions/08_slow_text.py` — 장치 없는 `SlowTextController`(인식 결과·시각 → 배율·이유) + 06에 얹은 주행(`--trial`). `tools/yolo.py` `Detector`에 모델 경로·이름 파일 인자 추가(기본값 유지). |

## 데이터 · 모델 만들기 (코랩) — 하은님과 공동
1. 라즈봇 카메라로 실제 트랙에서 「천천히」 글씨 사진: 거리 30·50·80cm × 정면·왼쪽·오른쪽, 150장 이상. 감속 구간이 아닌 곳 100장 이상을 「없음」으로. 05 촬영 방식 또는 블랙박스 영상에서 0.5초마다 한 장. 얼굴 사진 제외. 카메라 각도 80°/25° 그대로.
2. 라벨링: Roboflow 또는 LabelImg, YOLO 형식, 학습:검증 8:2.
3. 코랩 GPU: ultralytics YOLO26n 사전학습에서 미세조정, imgsz 320, epochs 60 안팎, 검증 mAP50 0.8 이상 목표.
4. 내보내기(기존과 똑같이): `export(format="onnx", imgsz=320, opset=12, simplify=True)` → `models/slow_zones_320.onnx`, 이름 파일 `models/slow_zones.txt`.
5. 라즈봇에서 출력 모양 `(1, 4+클래스수, N)` 확인 후 저장 사진 채점(05 방식). 강사님 모델 파일은 그대로 두고 새 파일만 추가.

## 성공 기준 (숫자로)
- 모델: 저장 사진 채점 24/30 이상, 감속 구간 아닌 사진 30장에서 오탐 2장 이하, 라즈봇에서 초당 10번 이상.
- 글씨가 가까움 기준에 들어온 뒤 1.5초 안에 바퀴 명령 35 이하, 4초(±0.5초) 뒤 50 복귀. 5번 중 4번.
- 감속 중 STOP·사람·장애물 정지·재출발 그대로. 3번 중 3번.
- 감속 구간 아닌 곳에서 감속 0회(한 바퀴 기준). 5바퀴 중 4바퀴.
- 불빛·실제 속도 변화는 사용자가 눈으로 확인. 장치 없는 검증 `tools/test_slow_text.py`.

## 안전
- 감속은 속도를 내리기만 한다(배율 ≤ 1). 절대 한계 150 그대로. 기존 정지 규칙 우선.
- 35에서 바퀴가 도는지 상자 위에서 먼저 확인. 매 회차 사용자 안전 확인.
- 사진·영상·데이터셋은 Git에 올리지 않는다. onnx·이름 파일·채점표만 커밋.
