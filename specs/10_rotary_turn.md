# 지시서 10 · 정차 후 로터리 우측 진입 및 반바퀴 선회·탈출

## 목표
로고 앞 횡단보도 정지선에 정차된 상태에서 시작하여, 로터리 우측 바깥 궤적으로 깊숙이 진입하고 안쪽 원형 노란선을 완만하게 추종해 반바퀴(180도) 선회한 뒤 출구 양쪽 차선을 감지해 직진 탈출하고 정지하며 영상과 계산 기록을 남긴다.

## 규칙표
| 상황 (언제) | 행동 (무엇을) |
|---|---|
| 화면 읽기 | `missions/03_video.py`의 `LatestCamera`를 사용해 640×480 uint8 BGR 화면을 읽는다. 카메라는 단일 스레드로 수신하며 최신 화면을 공유한다. |
| 출발 전 안정화 (`READY`) | 프로그램 시작 직후 네 바퀴 속도 (0, 0, 0, 0)을 유지하며 1.0초간 카메라 및 센서 파이프라인을 안정화한다. |
| 우측 진입 기동 (`READY` -> `ENTERING`) | 1.0초 경과 후 우측 바깥쪽 차선으로 깊게 진입하기 위해 좌측 바퀴 38, 우측 바퀴 15로 1.8초간 강하게 우회전 기동한다. 조기 좌회전으로 인한 중앙 섬 충돌을 방지한다. |
| 차선 찾기 영역 | 하단 180~380행(`frame[180:380]`)을 차선 추종 관심영역(ROI)으로 사용한다. 로터리 곡률과 중앙 조형물 간섭을 줄이기 위해 07번(120~300)보다 하향 고정한다. |
| 노란색 선택 | OpenCV HSV에서 H 15~40, S 80 이상, V 100 이상인 점만 고른다. 07번과 동일한 범위를 유지한다. |
| 왼쪽·오른쪽 선 계산 | 차선 띠의 왼쪽 절반 x<320 평균을 왼쪽 선, 오른쪽 절반 x>=320 평균을 오른쪽 선으로 본다. 최소 노란 점 개수는 반쪽마다 50픽셀이다. |
| 반바퀴 선회 주행 (`CIRCLING`) | 로터리 안쪽 노란선(left)을 TARGET_X=270에 맞추는 완만한 비례 조향을 적용한다. 오차=위치−270, 보정=0.25×오차, 왼쪽 바퀴=30+보정, 오른쪽 바퀴=30−보정 (바퀴 범위 0~50). 안쪽 급격한 쏠림을 방지한다. 좌측 선 누락 시 우측 선−240px로 대체한다. |
| 오작동 방지 최소 시간 | 로터리 진입 직후의 잔여선 및 회전 중 로고 테두리 선으로 인한 조기 탈출 오작동을 차단하기 위해, 선회 시작 후 5.0초간은 출구 감지 조건을 일체 평가하지 않는다. |
| 엄격한 출구 감지 및 탈출 (`CIRCLING` -> `EXIT_DRIVE`) | 선회 시작 5.0초 경과 후, 양쪽 선이 모두 검출되고 차선폭이 220~340px 범위이며 차선 중심 candidate가 280~360px로 화면 중앙에 3프레임 연속 정렬되면 출구로 판정하고 양쪽 선 중심(320) 추종 주행(기본 속도 32)으로 전환한다. |
| 미션 완료 정지 (`EXIT_DRIVE` -> `COMPLETED`) | 출구 주행 전환 후 1.5초간 직진 주행을 유지한 뒤 네 바퀴 0으로 완전 정지하고 프로그램을 종료한다. |
| 화면 갱신 중단 | 마지막 새 화면 수신 후 0.5초 초과 시 `FRAMESTOP`으로 네 바퀴를 즉시 정지하며 자동 재출발하지 않는다. |
| `--check` 실행 | 실제 바퀴 명령을 전혀 보내지 않는다. 선 위치, 조향 계산치, 상태 전이 정보를 1초마다 출력하며 모터 드라이버를 초기화하지 않는다. |
| 영상 및 기록 저장 | 화면에 상태, ROI 박스, 타겟 기준선(270/320), 바퀴 속도를 표시하고 `results/videos/`에 15fps 블랙박스 영상으로 저장한다. 수치 기록은 `results/rotary_mission_{timestamp}.csv`에 기록한다. |
| 아무 키나 Ctrl+C | 즉시 정지하고 종료한다. 종료 시 네 바퀴 0 명령을 0.2초 간격 3회 전송한다. |

## 성공 기준 (숫자로)
- 시작 직후 1.0초 정지 대기 후 진입 기동(`ENTERING`, 바퀴 38/15, 1.8초)으로 전이되어 바깥쪽 트랙으로 진입해야 한다.
- 차선 추종 띠 180~379행에서 안쪽 선(left)을 TARGET_X(270)으로 추종할 때 비례계수 K=0.25, 기본속도 30, 최대 50 범위로 제어되어 안쪽 섬으로 침범하지 않아야 한다.
- 선회 개시 후 최소 5.0초 이전에는 양쪽 선이 일시 감지되더라도 `EXIT_DRIVE`로 전이되지 않아야 한다.
- 5.0초 이후 폭 220~340px 및 중심 280~360px 정렬이 3프레임 연속 감지되었을 때 출구 모드로 즉시 전환되고, 1.5초 직진 주행 후 네 바퀴 속도 0으로 정지해야 한다.
- `--check` 실행 시 모터 객체 미생성 및 모든 종료 경로에서 모터 정지 3회 안전 호출을 검증한다.

## 안전
- 기본 선회 속도 30, 탈출 속도 32, 바퀴별 최대 속도 50으로 제한한다 (프로젝트 한계 150 대비 저속 서행).
- 최저 속도는 0이며 후진 속도는 허용하지 않는다.
- 긴급 정지(키 입력, Ctrl+C, 프레임 지연 0.5초 초과) 시 네 바퀴 0 명령을 0.2초 간격으로 3회 반복하여 관성 주행을 차단한다.
- 비디오 파일 및 사진은 Git 커밋 대상에서 제외(`results/` 내 CSV 및 로그만 커밋)한다.

## 바꿔 볼 값
- 차선 추종 띠: 180~379행.
- 안쪽 선 추종 기준점 `TARGET_X`: 270 (중앙 섬으로 파고들면 280~290 쪽으로 증가, 바깥으로 밀리면 250~260 쪽으로 감소).
- 선회 비례 계수 `STEERING_K`: 0.25, 기본 속도 30, 최대 속도 50.
- 진입 회전 속도: 좌 38, 우 15, 지속 1.8초 (진입 궤적이 부족하면 시간 2.0초로 증가).
- 오작동 방지 최소 선회 시간 `MIN_ROTARY_SECONDS`: 5.0초.
- 출구 차선 유효 폭: 220~340픽셀, 유효 중심: 280~360픽셀.
- 탈출 주행 시간 `EXIT_DRIVE_SECONDS`: 1.5초.

## 변경 근거
- 2026-11-04 사용자 주행 관찰: 로터리 진입 시 너무 이른 좌회전으로 인해 안쪽 섬(대구대 로고)으로 파고들었고, 내부 선 오인식으로 원 중간에서 조기 정지 발생. 진입 우회전 기동을 1.8초(좌38/우15)로 강화하고, 안쪽 추종 타겟을 270px·K 0.25로 완화하여 회전 반경을 확보함. 출구 감지 조건을 폭 220~340px 및 중심 280~360px 3프레임 연속으로 강화하고 최소 선회 시간을 5.0초로 연장함.
